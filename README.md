## 维护方式

- 每轮新 QA：先建 `details/Q编号-主题.md` 细节文档，再在 QA.md 索引顶部登记一行（标题+结论+链接）
- QA 标题必须带北京时间日期；待办追踪置顶；里程碑推进时更新 `roadmap.svg` 节点状态（空心→实心）
- 飞书同步：QA.md 整篇覆盖飞书「创业决策QA档案」，写入后读回校验
